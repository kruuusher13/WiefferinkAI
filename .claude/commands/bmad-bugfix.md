# Bug Fix Workflow

You are starting the **Bug Fix Workflow** for GarageAI.

## Overview

A streamlined workflow for fixing bugs:

```
REPRODUCE → LOCATE → FIX → VERIFY
```

## Activation

1. Read the configuration from `_bmad/core/config.yaml`
2. Read the workflow from `_bmad/garage/workflows/bug-fix/workflow.md`
3. Follow the workflow instructions exactly

## Workflow Phases

1. **Reproduce** - Confirm and understand the bug
2. **Locate** - Find the root cause in code
3. **Fix** - Implement the minimal fix
4. **Verify** - Confirm fix and no regressions

## Start

Read and follow the instructions in `_bmad/garage/workflows/bug-fix/workflow.md`.
